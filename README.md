# Nexo Legal — Demo de Dorenio

Proyecto ficticio de muestra, no presta asesoría jurídica. Imágenes proporcionadas por el usuario. No usar las fotografías promocionales de abogados de terceros como evidencia de equipo propio.

## Ver localmente
Abrir `index.html` en el navegador o usar VS Code > Live Server. También puedes ejecutar `npm start` y visitar `http://localhost:3000`.

## Heroku
Incluye `package.json`, `Procfile`, `server.js` y archivos estáticos, listo para despliegue en una app Node.js de Heroku. Ejecuta `git init`, `git add .`, `git commit -m "Nexo Legal demo"` y sigue el procedimiento de despliegue de tu app en Heroku.

## Personalización
El formulario NO envía por servidor: prepara un correo a `contacto@dorenio.com` para consultas sobre el diseño de muestra. Antes de utilizarlo con un cliente real, sustituye marca, servicios, profesionales autorizados, datos de contacto, políticas y avisos legales y verifica la licencia y autorización de todas las imágenes.


## Nexo Legal V2
Incluye ocho áreas de práctica inspiradas en las referencias (relacionadas con legislación colombiana), tres retratos ilustrativos generados y un globo flotante de WhatsApp de demostración. El número +00 000 000 0000 es un marcador ficticio sin enlace activo. Antes de utilizar el sitio para un despacho real, sustituir el contacto, verificar áreas de práctica y jurisdicción, reemplazar perfiles y acreditar habilitación profesional.
